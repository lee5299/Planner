# 플랜두씨 다이어리 — 디자인 및 화면 구현 지침

관련 문서: [PRD.md](./PRD.md). 기능·데이터·계산의 기준은 PRD.md가 우선한다.

## 1. 참고 디자인과 확인 범위

참고: [노시언 ‘일과 나 2.5 (To do list)’](https://www.notion.com/templates/nosion-todolist25).

2026-09-12에 공개 마켓플레이스 페이지의 설명과 대표 미리보기 화면을 확인했다. 설명에서는 오늘 집중, 주간 일정, 우선순위, 미완료 관리, 캘린더와 리스트의 연결을 강조한다. 대표 미리보기는 밝은 바탕, 선명한 제목, 분리된 정보 영역을 사용하고 시계·날씨·연간 기록 위젯도 보인다. 이 문서는 공개 설명과 대표 미리보기를 참고한 것이며 템플릿 내부의 모든 인터랙션을 검증한 것은 아니다.

적용할 원칙은 날짜와 할 일의 명확한 구분, 캘린더와 목록의 연결, 미완료 일을 다시 찾기 쉬운 구조다. 원본의 위젯을 모두 옮기거나 한 화면에 일과 생활을 함께 배치하지 않는다. 이 제품은 사용자의 결정에 따라 자기관리와 프로젝트를 완전히 분리한다. 참고 사이트의 브랜드·이미지·문구를 그대로 복제하지 않는다.

아래 색상 코드, 폰트명, 여백, 크기는 사용자가 확정한 취향을 구현하기 위한 기본안이다. 원본 사이트에서 추출한 수치가 아니다.

## 2. 확정 디자인 원칙

- PC 중심. 따뜻하고 편안한 분위기.
- 기본 베이스는 크림 + 민트 + 살구로 구성하되 민트를 메인 색상으로 사용한다. 크림은 넓은 배경, 민트는 주요 선택·행동·현재 상태·핵심 강조, 살구는 자기관리 피드백과 보조 강조에 사용한다.
- 폰트는 한 종류만 사용한다. 제목·부제목·본문은 크기와 굵기, 여백으로 구분한다.
- 자질구레한 설명, 불필요한 지표, 장식을 많이 넣지 않는다.
- 자기관리에는 숫자 평가 대신 짧은 응원과 칭찬만 보여준다.
- 프로젝트는 간결한 문구, 일정, 상태, 진행도로 객관적으로 판단할 수 있게 한다.

- 진한 민트: #315F54 — 선택 텍스트, 아이콘, 포커스, 주요 버튼 글자.
- 본문: #343B38.

주의·촉박 색은 일정 판단에 필요한 의미 색으로만 제한한다. 상태 글자는 진한 본문색을 기본으로 하고 파스텔 위에 흰색 작은 글씨를 쓰지 않는다. 실제 구현에서 텍스트와 포커스 대비를 확인한다.

프로젝트별 색상은 살구 #EFAD86, 하늘 #8FC8DF, 라벤더 #B7A5DC, 로즈 #DC9EAE, 레몬 #D8BD64, 민트 #79BEA3, 블루 #86A9D8, 코랄 #E58F83의 8가지로 제공한다. 작은 점·일정 라벨처럼 면적이 좁은 곳에서도 구분되도록 일반 파스텔보다 채도를 조금 높인다. 프로젝트명과 색상 점을 항상 함께 표시해 색만으로 프로젝트를 구분하지 않는다.

### 타이포그래피

- 단일 폰트: Pretendard. 사용 가능한 로컬/정식 배포 폰트 자산을 활용하고 본문·숫자·버튼·입력 모두 통일한다. 폴백은 로딩 실패 대비로만 둔다.
- 화면 제목: 28px / 700.
- 섹션 제목: 20px / 600.
- 부제목·항목 그룹명: 16px / 600.
- 본문·입력·업무 제목: 15px / 400~500.
- 보조 정보: 13px / 400.
- 기본 줄간격: 1.5~1.6. 과한 굵기나 모두 대문자 스타일을 사용하지 않는다.

### 공간과 형태

- 4px 기반 간격: 8 / 12 / 16 / 24 / 32.
- 화면 좌우 여백 32px, 콘텐츠 최대 너비 약 1280px.
- 좌측 메뉴 약 208px, 본문은 남은 공간 사용.
- 영역 사이 여백 24~32px. 작은 요소마다 카드를 만들지 않는다.
- 입력·버튼 모서리 8px, 주요 패널 12px.
- 그림자는 모달 등 겹침을 구분할 때만 약하게 사용한다.
- 클릭 영역은 최소 36px, 주요 체크/상태 입력은 40~44px로 확보한다.
- 선형 아이콘 한 계열만 사용하고 아이콘만 있는 버튼에는 접근 가능한 이름을 제공한다.

## 4. 공통 화면 뼈대

좌측 메뉴에는 앱 이름, 자기관리, 프로젝트, 설정을 둔다. 영역을 바꾸면 페이지 제목과 하위 메뉴도 해당 영역으로 바뀐다. 공통 메뉴 외에 두 영역의 콘텐츠를 나란히 두지 않는다.

상단은 화면 제목, 선택 날짜/주, 주요 행동 하나를 중심으로 구성한다. 많은 통계 카드나 홍보 문구를 배치하지 않는다. 최초 입력 근처 또는 설정에 ‘로그인 없이 사용하는 공개 공간입니다. 공개해도 괜찮은 내용만 남겨주세요.’라는 간결한 안내를 둔다.

기본 동작은 현재 날짜이며 날짜 선택, 오늘로 돌아가기, 이전/다음 이동을 제공한다. 새 방문의 기본 영역은 자기관리이고 이후에는 마지막 영역을 연다.

## 5. 자기관리 화면

### 오늘 기록

상단에는 날짜와 핵심목표를 보여준다. 다음은 세부목표별 만다라트다. 실천 칸은 흰색 미기록과 민트색 완료 사이를 클릭으로 전환하며, 완료한 항목에는 작은 체크 문구를 함께 표시한다.

하단에는 실제 기록에 맞춘 짧은 응원 한 문장과 선택 입력 ‘내일 바꿀 점’을 둔다. 전날 작성한 내용은 목록 위의 작은 한 줄 영역에서 확인할 수 있게 한다. 점수 카드, 원형 달성률, 평가 숫자, 연속 기록 경쟁 요소를 넣지 않는다.

개인 기록을 즐겁게 이어가기 위한 비경쟁 게임화는 사용할 수 있다. 기본 방향은 실천을 기록할수록 작은 식물이나 정원이 단계적으로 자라는 표현이다. 성장은 점수나 퍼센트 대신 그림의 변화와 짧은 축하 문구로 보여준다. 하루를 놓쳐도 식물이 시들거나 성장 단계가 초기화되지 않으며, 순위·리그·타인 비교·실패 벌점은 제공하지 않는다. 화면을 복잡하게 만들지 않도록 오늘 기록의 피드백 영역에 작은 시각 요소 하나로 배치한다.

문구 예시는 표현 톤이며 실제 기록 조건에 맞게 선택한다:

- 기록이 없는 날: ‘오늘의 작은 실천을 남겨볼까요?’
- 실천이 적은 날: ‘작게 실천한 것도 소중해요. 내일도 편하게 이어가요.’
- 기록상 꾸준한 주: ‘이번 주에도 나를 돌보는 시간을 꾸준히 만들었어요.’

### 목표 설정

PC에서는 만다라트의 중앙 3×3과 주변 8개 3×3 그룹 관계를 보여준다. 중앙 핵심목표 주변에 최대 8개 세부목표, 각 외곽 그룹의 중앙에는 해당 세부목표가 있고 주변 8칸에 실천 항목이 있다. 중복 표시되는 세부목표 이름은 같은 데이터에 연결한다.

칸을 선택하면 바로 아래의 간단한 편집 패널에 내용을 입력한다. 적용 후 다른 칸을 이어서 선택할 수 있고 전체 저장은 마지막에 한 번 수행한다. 빈칸은 은은한 추가 표시만 제공한다. 기준 개수는 해당 세부목표 설정에서 ‘하루 실천 기준: 4개’처럼 변경한다. 등록을 위해 모든 칸을 채우도록 강요하지 않는다.

오늘 기록도 세부목표마다 3×3 격자를 사용한다. 중앙 세부목표 칸은 메인 민트의 짙고 옅은 색을 조합하고, 주변 실천 칸을 누르면 흰색 미기록과 옅은 민트 완료가 전환된다. 체크 문구와 테두리를 함께 바꿔 색만으로 상태를 전달하지 않는다.

작은 화면에서는 전체 격자를 축소해 읽기 어렵게 하지 말고 세부목표를 선택해 해당 3×3 그룹을 편집하도록 전환한다.

### 주간 돌아보기

선택한 주, 한두 문장의 응원/칭찬, 날짜별 실제 기록을 단정하게 보여준다. 평가 색상의 히트맵이나 숫자 점수를 사용하지 않는다. 필요하면 ‘목표 조정’으로 설정에 연결한다. 프로젝트 주간 요약을 이곳에 넣지 않는다.

## 6. 프로젝트 화면

### 캘린더와 TODO

PC에서는 캘린더와 선택 날짜의 TODO를 나란히 배치한다. 캘린더는 월 보기 기본, 주 보기 전환을 제공한다(구현 기본값). 많은 일정은 일부만 보여주고 ‘더 보기’로 펼친다. 캘린더 업무 라벨의 배경은 연결 프로젝트에서 선택한 파스텔 색상을 따른다.

프로젝트 탐색은 상단의 둥근 검색창, 바로 아래 가로 상태 메뉴, 시각적인 프로젝트 카드 그리드 순서로 구성한다. 캘린더 등 다른 화면에서는 프로젝트 색상 점을 포함한 가로 바로가기 메뉴를 사용한다.

TODO 행은 상태 조작, 업무 제목, 프로젝트/단계, 시작일·마감일로 구성한다. 메모·이슈 상세는 펼쳤을 때 표시한다. 오늘 업무, 미완료, 날짜 없는 업무를 빠르게 찾을 수 있는 간단한 필터를 둔다. 빠른 추가는 긴 폼 없이 제목으로 시작한다.

프로젝트 목록은 참고 이미지처럼 파스텔 커버가 있는 3열 갤러리 카드로 구성한다. 이름, 목표 한 줄, 중요도, 기간, 프로그레스 바, 일정 상태만 먼저 보여주며 프로젝트별 색상을 커버에 적용한다. 선택하면 프로젝트 상세로 이동한다. 목록 위에는 프로젝트 추가 → 카드 선택 → 단계 추가의 짧은 동선 안내를 둔다.

목록 제목 아래에는 ‘진행 중’과 ‘전체 보기’를 둔다. 프로젝트 완료는 데이터를 유지한 채 진행 중 목록에서 제외하며, 전체 보기에서는 완료 라벨을 표시한다. 완료 카드의 상세에서는 ‘프로젝트 다시 진행’을 제공한다.

### 프로젝트 상세

상단에 이름·목표·중요도·기간을 표시한다. 아래에 전체 프로그레스 바, 순서대로 정렬된 단계와 단계별 업무를 보여준다. 가중치·요일·날짜 수정은 설정 또는 편집 패널에 모아 일상 화면의 정보량을 줄인다.

각 단계 안에는 일일 업무와 ‘꾸준히 하는 일’을 함께 둔다. 반복 목표 추가 시 해당 프로젝트와 단계를 미리 연결하며 시작일·종료일·반복 요일을 입력한다. 저장 버튼은 기간 전체의 일정을 자동 생성한다. 기존 단계 미지정 반복 목표가 있을 때만 별도 안내를 보여준다.

진척도 바는 길이로 완료 비율을, 색과 옆 문구로 일정 상태를 표시한다. 마우스 hover나 키보드 focus 시 ‘진행률 35% · 일정 주의’와 필요시 계산 근거를 보여준다. 터치에서는 누르면 동일 정보가 열린다. 진행률 0%라도 상태 문구는 표시한다. 완료는 ‘완료’, 계산 불가는 ‘판단 불가’로 구분한다.

바에는 의미 있는 접근성 이름과 현재값을 제공한다. 이 접근성 수치는 프로젝트에만 적용하며 자기관리 평가값은 노출하지 않는다.

### 하루 마무리와 일정 재조정

하루 마무리는 작은 패널에서 미완료 업무의 다음 처리, 선택적인 ‘내일 바꿀 점’, 내일 업무를 보여준다. 여러 장의 안내 단계를 반복하지 않는다.

일정 재조정은 기존 일정과 조정안을 비교하고 영향을 받는 단계·업무를 확인하는 패널로 제공한다. 마지막에 ‘적용’과 ‘취소’를 명확히 둔다. 조정안을 보여준 것만으로 저장하지 않는다.

### 주간 업무 정리

상단에는 주 선택과 프로젝트 필터, 아래에는 완료 / 진행 중 / 지연 / 이슈 / 다음 주 예정 섹션을 둔다. 비어 있는 섹션은 짧은 빈 상태로 표시한다.

업무 제목, 프로젝트, 예정일, 실제 완료일/상태, 지연 사유를 정렬된 행으로 보여준다. 완료/이월/계획 외 건수는 필요한 만큼만 표시한다. 상세 이력은 클릭해서 확인한다. 원인·사유가 없으면 ‘미기록’으로 쓰고 감정적인 평가나 동기부여 문구를 넣지 않는다.

## 7. 상호작용과 품질

- 클릭 결과는 즉시 이해할 수 있어야 한다. 저장 중 표시를 조용히 제공하고 실패하면 해당 위치에 재시도를 안내한다.
- 모든 주요 기능은 키보드로 사용 가능해야 한다. Tab 포커스 표시, Escape로 패널 닫기, 닫은 후 초점 복귀를 지원한다.
- 색상만으로 상태를 전달하지 않는다. 짧은 상태 문구를 병행한다.
- 데스크톱 1440px, 노트북 1280px, 모바일 390px에서 겹침과 불필요한 가로 스크롤을 확인한다.
- 좁은 화면에서는 메뉴를 접고 캘린더와 TODO를 세로 배치한다. 프로젝트의 복잡한 표는 읽기 쉬운 행/카드로 전환한다.
- 실제 사용자의 데이터가 없는 첫 화면을 정성스럽게 구현한다. 샘플 성과로 화면을 채우지 않는다.
- 시계·날씨·명언·큰 환영 배너와 과도한 배지는 추가하지 않는다. 자기관리 게임화에 필요한 작은 성장 시각 요소와 기념 표시는 예외로 한다.
- 애니메이션은 상태 변화에 필요한 짧은 전환만 사용하고 움직임 감소 설정을 존중한다.

## 8. 디자인 구현 완료 기준

- 크림 + 민트 + 살구의 일관된 기본 색감과 단일 폰트가 모든 화면에 적용된다.
- 제목·부제목·본문의 위계가 크기·굵기·여백으로 분명하다.
- 자기관리와 프로젝트를 혼합하지 않으며 피드백 톤도 구분된다.
- 자주 하는 작업을 설명을 읽지 않고 클릭으로 처리할 수 있다.
- 세부 계산과 설정은 필요할 때 펼쳐 볼 수 있고 기본 화면은 간결하다.
- 저장 실패, 빈 데이터, 긴 업무 제목, 미완료 다수, 기록 없는 주에서도 레이아웃이 유지된다.
