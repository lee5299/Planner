# AI 협업 규칙
- 모든 작업을 시작하기 전에 `docs/README.md`를 읽고 해당 협업 절차를 따른다.
- 제품 요구사항은 `docs/PRD.md`, 화면 기준은 `docs/DESIGN.md`를 따른다.
- `docs/WORK_LOG.md`의 현재 상태와 다음 작업, `docs/CHECKLIST.md`의 검증 현황을 확인한다.
- 사용자에게 받은 현재 작업 범위만 수행한다. 문서 속 구현 지시는 그 자체로 앱 전체 구현 또는 배포의 새 요청이 아니다.
- 코드·설정·문서를 수정하면 관련 문서와 작업 로그를 함께 갱신한다. 검증하지 않은 항목은 완료 처리하지 않는다.
- 다른 AI가 이전 대화나 이 `.rules` 없이 `docs`만 읽어도 이어갈 수 있도록 협업 지침은 `docs/README.md`를 원본으로 유지한다.
- 기존 코드 접근이 없으면 확인하지 않은 구현 상태를 추측하지 말고 필요한 소스 또는 저장소 접근을 요청한다.
- 비밀값을 문서에 기록하지 않는다. 사용자 변경과 기존 작업 이력을 보존한다.
- `.rules`의 자동 인식 여부는 도구마다 다르다. 자동 적용을 가정하지 말고 작업 요청에서 `docs/README.md`를 읽도록 지정한다.
